A simple and effective plugin for adding custom CSS and JavaScript to your WordPress site.

== Description ==

The Custom CSS and JS Editor plugin allows users to easily add custom CSS and JavaScript to their WordPress website without modifying theme files. This plugin provides a simple editor interface where you can insert your code and apply it either globally or on specific pages.

You can add custom styling, scripts for dynamic functionality, or even third-party code to extend your site's behavior. Whether you're a beginner looking for an easy way to add custom code or an advanced developer wanting more control, this plugin provides a flexible and efficient solution.

== Installation ==

This section describes how to install the plugin and get it working.

1. Upload `custom-css-and-js-editor.php` to the `/wp-content/plugins/` directory.  
2. Activate the plugin through the 'Plugins' menu in WordPress.  
3. Go to the "Custom CSS/JS" menu in the WordPress dashboard to add your custom CSS or JS.
